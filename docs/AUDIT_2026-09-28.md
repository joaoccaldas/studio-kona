## How the graphics are made

Public data (OSM, NAIP/Esri imagery, AWS terrain + bathymetry, Wikimedia refs) → Python ingest in a local
metric frame (origin Kailua Pier 19.639162, −155.996808) → headless Blender builds geometry procedurally
(`blender/p1.py`: extruded OSM buildings with roof colours sampled from imagery, pier, 580 racked bikes,
heiau, buoys) → glTF (`kona_p1.glb` 8.8 MB) + 2048² island heightmap + 79 streamed tiles → Three.js 0.186
(Gerstner ocean, BVH collisions, walk/bike/swim/drone, fog-of-war mask). Las Vegas adds a Cycles lightmap bake
(`BELLAGIO_source/blender/build.py`); porting it to Kona is the largest visual upgrade (#14).

## Game design direction

Loop: pack → land at KOA → challenge → XP + Credits + medals → spend in town/locker → pier racks fill with
unlocked bikes → a new real-date day tomorrow. Regions lift from fog of war: Kailua Bay and pier, Aliʻi
Drive, Palani and Queen K, Energy Lab, Hāwī, South Kona, beaches, Volcano, Maunakea. Race-day live mode on
10 Oct. Credits are earned only (no real-money purchases in v1).

## Accounts and backend

Play first as a guest; upgrade to an account after the first reward (Supabase anonymous sign-in → magic link /
Google / Apple). Tables: profiles, saves, ledger (append-only), unlocks, results. RLS per player; the client
never writes balances. Only the anon key ships in the static site.
